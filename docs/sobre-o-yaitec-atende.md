# Sobre o YAITEC Atende

O YAITEC Atende é uma plataforma de atendimento ao cliente com IA. Conecta agentes a canais de mensagem, responde dúvidas, abre chamados e escala para um humano quando necessário. Dados na região Brasil (São Paulo), aderente à LGPD.

## Funcionalidades principais

- Atendimento automatizado com IA em múltiplos canais de mensagem
- Abertura e gerenciamento de chamados de suporte
- Escalada automática para agente humano quando necessário
- Armazenamento e processamento de dados na região Brasil (São Paulo)
- Conformidade com a Lei Geral de Proteção de Dados (LGPD)

## Arquitetura

A plataforma conecta agentes de atendimento a canais de comunicação como WhatsApp, Instagram, e-mail e webchat. O processamento de linguagem natural com IA permite respostas automáticas precisas, e o sistema identifica quando uma conversa deve ser escalada para um atendente humano.
